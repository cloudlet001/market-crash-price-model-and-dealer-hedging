# 急跌 / 崩盤：造市商避險與軋空互動筆記

> 本專案探討市場在急跌或崩盤時，**投資人（散戶、機構）** 與 **造市商（Market Maker）** 的避險行為如何形成「加速下殺 → 回補軋空」的兩階段微觀價格行為。

本專案提供單一純靜態、無外部相依的互動式筆記網頁：

- **VIX 與成交量動態模擬**：拖曳 VIX 觀察造市商避險狀態與量能倍數。
- **急漲鏡像**：Call 端與 Put 端的結構對稱與差異分析。
- **限制與實務修正**：淨負 Gamma 前提、恐慌暫停等實務考量。
- **完整逐字稿與摘要**：便於逐字研讀與複習。

## 核心機制摘要

1. **第一階段（機械性賣盤 加速趕底）**
   - 投資人虧損恐慌，賣股降槓桿並大量買進 Put 避險。
   - 造市商作為對手方賣出 Put，持有正 Delta、處於**淨負 Gamma**狀態。
   - 造市商為了維持 Delta 中性，必須順勢放空股票。價格越跌、Put Delta 越負、造市商越放空，賣壓疊加引發「爆量下殺」與超跌。

2. **第二階段（燃料點燃 軋空反彈）**
   - 當恐慌情緒達到極致（賣出高潮），跌勢趨緩或出現小幅反彈。
   - 三大催化劑發威：
     - **價格小幅反彈**：使價外 Put 進一步遠離價內。
     - **波動率下降（IV Crush / Vanna）**：VIX 自高檔回落，權利金縮水、Delta 快速變小。
     - **時間流逝（Charm / Theta）**：恐慌時買入的短天期 Put 時間價值急遽蒸發。
   - 造市商發現先前放空過多股票（過度避險），必須執行**機械性回補買盤**。
   - 買盤推升股價 ➔ Put 更貶值 ➔ 造市商回補更多 ➔ 觸發軋空（Short Squeeze）與 V 型反轉。
